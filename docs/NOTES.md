# Notes

## Why This Exists

Digital signage devices vary widely. RustPlayerBenchAI gives a consistent benchmark-shaped report that can be used for examples, tooling experiments, and future real-device metric collection.

## Known Limits

- Current values are generated from profiles, not collected from physical devices.
- It should not be marketed as a hardware lab replacement.
- Thresholds are currently built into the tool.

## Maintenance Notes

- Keep README wording clear about what is measured now.
- Add tests whenever device profile behavior changes.
- Avoid claiming FPS support until that feature exists.
