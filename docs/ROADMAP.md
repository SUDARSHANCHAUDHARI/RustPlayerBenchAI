# Roadmap

This is a solo-maintained roadmap. Items are practical possibilities, not promises.

## Planned

- Add more documented player profiles.
- Add CSV output for simple comparison tables.

## Completed

- Added configurable pass/warn/fail CPU and memory thresholds.

## Maybe Later

- Add real host metric collection on supported platforms.
- Add benchmark comparison between two saved JSON reports.
